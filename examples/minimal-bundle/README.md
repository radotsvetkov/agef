# Minimal Bundle Example (Structure-Only, v0.1.1)

This directory is currently a structure-only placeholder for a future minimal AGEF bundle example.

A real minimal AGEF v0.1 bundle (see `SPEC.md` Section 5) contains:

- `manifest.json`
- `events.bin`
- `objects/` (directory with one file per object hash)

The example is intentionally not populated yet because the reference exporter is not finalized at spec-repo level.

Akmon v2.0 Phase 4 (`export`/`import`) is expected to generate a concrete minimal bundle artifact, after which this directory will be updated with real files and verification guidance.
